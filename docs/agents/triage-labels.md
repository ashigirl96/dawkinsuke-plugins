# Triage Labels

スキルは triage の状態を 5 つの役割で呼ぶ。この file は、その役割をこの repo の issue tracker で実際に使うラベル名に対応づける。

| Label in mattpocock/skills | Label in our tracker | 意味                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | メンテナが評価する必要がある             |
| `needs-info`               | `needs-info`         | 報告者からの追加情報を待っている         |
| `ready-for-agent`          | `ready-for-agent`    | 仕様が固まり、AFK の agent が着手できる  |
| `ready-for-human`          | `ready-for-human`    | 人が実装する必要がある                   |
| `wontfix`                  | `wontfix`            | 対応しない                               |

スキルが役割を口にしたら（例: 「AFK-ready の triage ラベルを付ける」）、この表の対応するラベル名を使う。

実際に使うラベル名に合わせて「Label in our tracker」の列を書き換える。
