Call the Skill tool twice, for "grilling" and "domain-modeling".

Once the user confirms the shared understanding and the outcome is something to build, read `../to-spec/SKILL.md` and follow it without asking.

After the spec is published, judge whether the work fits in a single fresh context window. State the evidence first: the modules it touches and the tracer-bullet slices you expect. If it doesn't fit, read `../to-tickets/SKILL.md` and follow it. If it fits, stop there.
