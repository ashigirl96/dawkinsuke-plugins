# grilling の fork

## 事実調査がすべて返ってから round を出す

matt は subagent の調査を待たず、調査に依存しない質問をその round で先に出させる。調査がすべて返ってから round を出すように変えた。前提を決める質問が多く、事実が届く前に出すと質問がぶれるため。

## 答えで今後が分岐する問いだけを質問にする

matt は frontier の決定をすべて質問にし、それぞれに推奨を添えさせる。戻しにくいもの、他の issue や設計に波及するもの、ユーザーの価値観やリスクの許容でしか決まらないもの、ユーザーの頭の中にしか無い事実だけを質問にし、1 つの PR の中で戻せるものは推奨で決めて、round の末尾に「推奨で決めたこと」として理由と一緒に毎回並べるように変えた。推奨がそのまま通る質問は誤りを止めず、本当に効く質問への注意を薄めるため。用語や概念を固める段階では、後から効いてくるので小さく見える問いも質問にする。
